Add a secure contact form, email notifications, submission management, retention controls, and optional Fields integration.

== Description ==

Contact Form adds a focused visitor-contact workflow to Million Dollar Script sites. Administrators can configure recipient and sender details, spam controls, retention, email notifications, submission review, and privacy tools.

When the Fields extension is active, compatible field groups or individual fields can also be included without duplicating field definitions.

== Installation ==

1. Install and activate Million Dollar Script.
2. Install and activate this extension.
3. Open Million Dollar Script > Extensions > Contact Form.
4. Review email, spam-protection, retention, and privacy settings before publishing the form.

== Privacy ==

The extension stores submitted contact details and message content on the WordPress site. Configure retention for the site's operating and legal requirements, document the collection in the privacy notice, and use the included WordPress personal-data export and erasure support when applicable.
